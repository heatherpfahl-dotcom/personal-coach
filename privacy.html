Personal Coach privacy policy

Effective 15 October 2026.

Who uses it

Personal Coach is used by one person, its owner, to review the owner's own email and calendar. It runs only on the owner's computer and reads only the Google accounts the owner has listed in its configuration and signed in to personally. It is not offered to the public.

What it reads

The tool asks Google for two permissions, read-only access to Gmail (gmail.readonly) and read-only access to Google Calendar (calendar.readonly). It refuses to store any sign-in that grants more than those two, so it cannot send, change or delete email or calendar events.

  • From Gmail it reads messages from the last 14 days, skipping chats, spam, trash, drafts and Gmail's promotions, social and forums tabs. Messages from automated senders are kept as sender, recipients, subject, date and a few Gmail labels, without the message text. Other messages keep the same fields and their text, with quoted earlier replies removed and the remaining text cut to 1,500 characters for received mail and 4,000 for mail the owner sent.
  • From Google Calendar it reads events from 7 days before to 7 days after each run, keeping each event's start and end, whether it lasts all day, its title and type (such as focus time or out of office), the number of other attendees, the owner's response and whether the owner organised it. Descriptions, locations and the names and email addresses of attendees are not written to the extract.

Where the data goes

A script on the owner's computer fetches the data described above from Google and saves it as an extract, and code on the same computer computes reply times and calendar load from it. To write the weekly review, the extract, together with the previous week's review and the owner's own profile notes, is then sent to Anthropic's Claude service under the owner's own Claude account. That account has Anthropic's model-training setting turned off, so Anthropic does not train its models on this data and handles it under that account's retention terms, described in Anthropic's privacy policy. In that step Claude has no tools that can send email, browse the web or run commands, and it can write only inside the run's reports folder.

Sign-in tokens are stored in the macOS Keychain on the owner's computer. Apart from the Anthropic step, the tool has no server, no database and no copy of the data anywhere else.

What it keeps

The email and calendar extract is deleted when each run ends, or at the start of the next run if a run is interrupted, and the run keeps no transcript of the Claude session. What remains is the owner's weekly review, which names the people awaiting a reply and what they asked for and quotes a few sentences from messages, and a file of aggregate counts per account, such as messages sent and the median reply time, which holds no subjects or names. A log of the actions Claude took during each run, which can include short search terms, is also kept. All of these stay on the owner's computer until the owner deletes them.

Sharing and other uses

Personal Coach does not sell, share or transfer Google user data to anyone other than the owner, except for the Anthropic processing step described above. It does not use the data for advertising, and it does not change anything in the owner's Google accounts. Personal Coach does not use Google user data to develop, improve or train generalized AI or machine-learning models.

Personal Coach's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access for any account can be withdrawn at any time at myaccount.google.com/permissions, after which the tool can no longer read that account. Revoking access does not delete reviews already written. Those are removed by deleting the reports folder, and the stored sign-in tokens by deleting the tool's Keychain entries.

Contact

Questions about this policy can be raised as an issue on the GitHub repository that publishes this page.
